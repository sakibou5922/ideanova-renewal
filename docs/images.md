# 画像仕様書・生成指示（content-production-dept）

このフォルダに画像を置き、`src/data/images.ts` の `src` にパスを設定すると、サイト各所に反映されます（例: `hero: { src: '/images/hero.jpg', alt: '…' }`）。
未設定のスロットは当社制作の線画プレート（SVG）で自動的に代替表示されます。

## 1. スロット一覧

| キー（images.ts） | 用途 | 比率 / 推奨サイズ | 形式 | alt（案） |
| --- | --- | --- | --- | --- |
| `hero` | トップ右のメインビジュアル | 4:5 / 1200×1500px | JPEG (q80) or WebP | 「（写真の内容を記述）」— 装飾目的なら空文字 |
| `agri` | トップ diptych・事業内容 01 | 4:5 / 1200×1500px（トップは 16:10 にトリミング表示） | JPEG/WebP | 農業支援事業のイメージ（例: 収穫した野菜を箱に詰める手元） |

| `greeting` | 会社概要・代表挨拶横（任意） | 3:4 / 900×1200px | JPEG/WebP | 代表取締役 荒木裕子（本人写真の場合。肖像権の同意要） |

- 色調はサイトの紙色（#faf8f4）と馴染む**やや彩度を抑えた自然光**。強い彩度・HDR 風は避ける。
- 被写体は「土（緑・茶）」「水（透明・淡いローズ）」の対比が出るものを選ぶ。
- 文字入り・ロゴ入り・実在ブランドの写り込みは不可。人物の顔が写る場合は肖像権の同意を取る。

## 2. AI画像（GPT 等）で生成する場合のプロンプト

生成画像は「実在の店舗・商品・人物」に見える表現を避け、**イメージ写真**として使うこと。化粧水の効能を示唆する表現（肌の変化など）は薬機法上の懸念があるため生成しない（法務確認要）。

### hero（4:5、1200×1500）
```
日本の地方の農地と水をテーマにした、静かで上質なイメージ写真。早朝の柔らかい自然光。
手前に瑞々しい若い芽や葉、背景にぼけた畑と遠くの山並み。画面のどこかに水滴か水面の反射をさりげなく入れる。
色調は生成りの紙に馴染む、やや彩度を抑えた緑と淡いローズ。
構図は縦位置 4:5、被写体は右寄せで左側に余白。文字・ロゴ・人物の顔は入れない。フィルム写真のような質感、過度なHDR禁止。
```

### agri（4:5、1200×1500）
```
収穫したばかりの野菜（葉物、トマト、根菜）を木箱や段ボールに詰める人の手元のクローズアップ。
日本の農家の作業場、自然光、俯瞰やや斜めの構図。顔は写さない。
色調は落ち着いた緑と土の茶、背景は明るくシンプル。縦位置 4:5。文字・ロゴなし。
```

### cosme（4:5、1200×1500）
```
ラベルのない透明ガラスの化粧水ボトルを、白〜生成りの布や石の上に置いたミニマルなプロダクトイメージ。
柔らかい窓光、水滴と淡い影、背景に淡いローズ〜ベージュのグラデーション。
色調は上品で清潔感のある低彩度。縦位置 4:5。文字・ロゴ・実在ブランドを想起させる形状は避ける。
```

### greeting（3:4、900×1200）— 本人写真を使う場合は撮影推奨
```
（AI生成ではなく実撮影を推奨）自然光の入る室内で、上半身、視線はカメラ、背景は無地または軽くぼかしたオフィス。
```

## 3. 書き出し・配置

1. 上記サイズで書き出し（JPEG q80 または WebP q80、ファイル名は `hero.jpg` / `agri.jpg` / `cosme.jpg` / `greeting.jpg`）。
2. このフォルダ（`public/images/`）に置く。
3. `src/data/images.ts` の `src` を `'/images/hero.jpg'` のように設定し、`alt` を記入する。
4. `npm run dev` で表示確認。トップの diptych は 16:10 に中央トリミングされるため、主要被写体は中央に寄せる。

## 権利・法務確認事項
- 現行サイト画像: 撮影者・購入元・ライセンス範囲を確認（要確認）。
- AI 生成画像: 生成サービスの商用利用規約を確認。人物・実在物に似せない。
- 化粧水の表現: 効能・効果を連想させるビジュアル／コピーは薬機法・景表法の確認要。
